
Skin: Naruto Animated Xbox One for Gamepad Viewer

Instruções de Instalação:

1. Vá para https://gamepadviewer.com
2. Clique no ícone de engrenagem ⚙ no canto superior direito
3. Em "Controller Skin", clique em "Import"
4. Selecione os arquivos da pasta desta skin (ou use a opção ZIP se disponível)
5. A skin será aplicada automaticamente

Créditos: Criado com base no tema do anime Naruto.
